# Contributing

- Work from a dedicated Git worktree. Read [AGENTS.md](AGENTS.md) for kit-specific limits.
- Use the [project tooling guide](docs/project-tooling.md) for prerequisites, Beads, and release setup. Keep backlog and status in Beads; use [Spec Kit](specs/README.md) for consequential changes.
- Run the [offline checks](README.md) before opening a pull request. Review substantive imports and behavior changes independently.
- Use atomic Conventional Commits. Keep credentials, private identifiers, managed-service inputs, and raw diagnostic output out of commits and PR text.
