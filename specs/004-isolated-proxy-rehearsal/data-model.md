# Data model: isolated rehearsal

- **Proposal**: Versioned operator-supplied manifest; explicit overlay and pin files and reviewed SHA-256 values; approved guest runtime bundle and image identifiers; optional native receipt required when the pin declares it; one named local fixture set. Host paths are invocation inputs, never receipt values. Manifest unknown fields refuse. No arbitrary shell hooks, environment map, destination URLs or launcher argv.
- **Run scope**: Non-reusable run ID; exclusive private record created before allocation; sealed runtime and input identities; run-owned hypervisor handle, scratch owned by that record, and supervised guest endpoint. The handle/local paths are private recovery state, not public results. Allocation is distinct from startup; admission precedes all candidate-bearing operations.
- **Guest result**: Bounded typed message with run ID, overlay/pin and rendered proposal digests, effective YAML/behavioral manifest identity, verified runtime digest, fixed-vocabulary checks and exclusions. The canonical digest excludes the ephemeral key and raw output. Unknowns are explicit nulls. A guest message is untrusted input to the host, not proof of host teardown.
- **Host receipt**: Version, run ID, status (`refused`, `failed`, `incomplete`, `passed`), nullable guest evidence, failure class, supervisor closure proof and timestamps. No success without all required guest checks, provenance continuity, and host-confirmed closure. Sanitized evidence survives disposal of the guest.

**State machine**: `reserved → admitted → running → closing → settled`. A pre-admission refusal can settle only if nothing was started. A worker failure with proved closure settles `failed`. Owner loss, unknown closure or contradictory record leaves an `incomplete` result unless a surviving authority proves closure and records a settled failure; the next invocation refuses unresolved records before allocating a scope. A settled failure is not authorization to test again autonomously. Reconciliation can act only on the scope owned by the original record.
